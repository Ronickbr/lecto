# Lecto — Plataforma de Compreensão Leitora

Projeto independente (sem dependências de terceiros de geração de código).

## Stack

- TanStack Start (SSR + server functions)
- React 19
- Tailwind CSS 4
- Supabase (Postgres, RLS, Auth, Storage)
- Vercel AI SDK (provedor OpenAI-compatível configurável)
- Playwright (E2E)
